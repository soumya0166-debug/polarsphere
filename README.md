# POLARSPHERE
> **The Polar World, Through India's Eyes**  
> *A Modern Digital Platform for Polar Science Outreach, Knowledge Repository, Station Telemetry & Field Expeditions*

Under the stewardship of the **Ministry of Earth Sciences (MoES), Government of India** and the **National Centre for Polar and Ocean Research (NCPOR)**, PolarSphere provides unified telemetry, open cryospheric data, and field expedition archives across Antarctica, the Arctic, the Southern Ocean, and the Himalaya (Third Pole).

---

## ❄️ Key Features

- **Interactive Polar Geosphere**: Real-time 3D canvas featuring South Polar (Antarctica), North Polar (Arctic), and Tri-Polar Global Grid projections with interactive station beacons and sensor telemetry.
- **India’s Four High-Latitude Bastions**:
  - **Bharati Station** (*Larsemann Hills, East Antarctica* - Est. 2012)
  - **Maitri Station** (*Schirmacher Oasis, Queen Maud Land* - Est. 1989)
  - **Himadri Station** (*Ny-Ålesund, Svalbard, Arctic* - Est. 2008)
  - **Himansh Station** (*Chandra Basin, Western Himalaya, 4,080m ASL* - Est. 2016)
- **Expedition Mission Control**: Live tracking of the **44th Indian Scientific Expedition to Antarctica (ISEA-44)** aboard polar vessel *MV Vasiliy Golovnin*, waypoint navigation logs, swell/sea-ice telemetry, and field dispatches.
- **Polar Data Explorer & Open Science**: FAIR-compliant metadata catalog with DOIs, direct NetCDF/GeoTIFF/CSV download configurations, programmatic API snippets (Python, cURL, R), and automated APA/BibTeX citation tools.
- **Polar Guide (Scientific AI Shell)**: Interactive query assistant for polar science exploration, station specs, and glacier dynamics.
- **Global Search (`Ctrl+K`)**: Instant indexed search across stations, expeditions, open datasets, and daily field logs.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/soumya0166-debug/polarsphere.git

# Navigate to directory
cd polarsphere

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Building for Production
```bash
npm run build
```
